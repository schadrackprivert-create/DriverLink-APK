# DriverLink — APK de pruebas

Distribución de APK de DriverLink para pruebas autorizadas. Este repositorio no contiene el código fuente ni claves de firma.

[Descargar DriverLink 0.2.2](https://github.com/schadrackprivert-create/DriverLink-APK/releases/download/v0.2.2/DriverLink-0.2.2-prodDebug.apk)

## Instalación

Instala esta versión inicial manualmente encima de la anterior, sin desinstalar ni borrar datos. Se requiere Android 8 o posterior. Es una APK de pruebas, no una publicación de Play Store.

## Actualizaciones

Desde 0.2.2, la aplicación consulta el manifiesto de la última publicación al entrar en Inicio o Perfil, como máximo una vez al día y fuera de navegación/PTT activo. Cuando hay una versión superior ofrece Actualizar o Más tarde. La descarga verifica tamaño, SHA-256, paquete y firma; Android exige confirmar la instalación. Más tarde aplaza el aviso de esa versión siete días.

Una compilación local no publica una actualización. Cada publicación debe ser autorizada. No se instala silenciosamente ni se actualiza una app cerrada por sí sola.

La versión 0.2.2 no mostrará un aviso para actualizar a sí misma. Las versiones anteriores sin esta configuración necesitan la instalación manual inicial.

Consulta las notas de cada release para conocer las pruebas realizadas y limitaciones pendientes.
